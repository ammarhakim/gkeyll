DESC to Gkeyll Geometry Workflow
=================================

Step 1: Extract geometry from DESC equilibrium -> .npy arrays *required having conda env with DESC installed activated
  python get_field_coords.py <equilibrium.h5> <npy_output_dir>

Step 2: Convert .npy arrays -> .gkyl binary files
  python numpy-to-gkyl.py <npy_input_dir> <gkyl_output_dir>

Step 3: Compute derived geometry and nodal-to-modal conversion -> final .gkyl files
  make desc_grid
  ./desc_grid <gkyl_input_dir> <name>
  Output goes to <name>_geometry/, files are named <name>-<quantity>.gkyl

Full example (W7-X):
  conda activate DESC
  python get_field_coords.py w7x_equilibrium.h5 w7x_npy
  python numpy-to-gkyl.py w7x_npy w7x_gkyl
  make desc_grid
  ./desc_grid w7x_gkyl w7x

  # Final output: w7x_geometry/w7x-bmag.gkyl, w7x-mapc2p.gkyl, etc.

Optional: plot_*.py scripts can verify geometric quantities.
